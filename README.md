# GORILLA.BAS: Vibe Edition

A modern, browser‑based homage to the classic Gorilla.bas, built as a playful example of vibe coding.

## Demo
[Play it here](https://bbenko.github.io/gorilla-bas-vibe/)

## Features
- Turn‑based banana lobbing with wind and gravity
- Randomized city skyline with destructible buildings
- Elliptical explosions, simple SFX, and celebratory animation
- Clean, single‑file setup (no build tools)

## Controls
- Enter **Angle** and **Velocity**
- **Throw** button or press **Space / Enter**
- After a hit, click **Next Turn** (or press **Space / Enter**) to generate a new city

## Run locally
Open `index.html` in your browser.

## Notes
This project intentionally keeps everything in one HTML file to highlight fast iteration and “vibe‑coding” flow.
